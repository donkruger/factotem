NanoClaw isn't responding. Run the four steps below in order — each starts the layer beneath the next. The status indicator will turn green when the dashboard is reachable again.

1 Open Docker Desktop

Docker provides the container runtime for every NanoClaw agent. It must be running before the next two steps will work.

open -a Docker

Or click the Docker whale icon in /Applications → wait until the icon stops animating.

2 Start OneCLI

OneCLI is the credential gateway. Without it, agent containers spawn but get HTTP 401 from Anthropic.

cd ~/.onecli && docker compose up -d

3 Restart NanoClaw

Reloads the orchestrator so it picks up Docker + OneCLI being available.

launchctl kickstart -k gui/$(id -u)/com.nanoclaw

4 Verify

Open the dashboard. If it loads with green badges, you're back. The status indicator above will also turn green.
